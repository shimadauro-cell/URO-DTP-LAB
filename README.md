# URO DTP LAB（配布用）

同人誌・冊子制作 DTP ソフト「URO DTP LAB」の、アプリ内の更新のための配布場所です。
アプリが起動したときにここの latest.json を読み、新しい版があれば、変わった部品（packs/）だけをダウンロードします。
latest.json には署名（latest.sig）が付いていて、アプリは署名と中身の値を確かめてから更新します。

## 本体のダウンロード

はじめて使うときは、右側の「Releases」（リリース）から、いちばん新しい「URO DTP LAB ○○.zip」をダウンロードしてください。
https://github.com/shimadauro-cell/URO-DTP-LAB/releases/latest

1. zip を右クリック →「すべて展開」で、好きな場所に広げます。
2. 広げたフォルダーの「URO DTP LAB.exe」をダブルクリックすると起動します（インストールは要りません）。
3. 初めて起動するとき、Windows の警告が出たら「詳細情報」→「実行」を押してください。

一度入れたあとは、新しい版が出るとアプリが知らせてくれます（アプリの中で更新できます）。
